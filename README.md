# starship-builder

Using manifold cad, this is intended to be an easy to use starship designer for agents and humans to tinker with. First page will be a demo. 

We use this library

https://github.com/elalish/manifold 

The intention is to give this to Claude, so I am going to evolve it from a blocky design to a full actual manifold using a designer system to allow easy evolution and manipulation of the structures required to build fantasy starships. None of them are intended to be physics-realistic, just a way to generate interesting starship models
